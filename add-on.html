2. Core Codebase Audit & Gap Analysis

⚠️ 1. Missing RFC Threading Headers

Follow-ups currently prepend Re: to the subject line, but lack Message-ID, In-Reply-To, and References. Modern Gmail and Outlook treat them as detached new emails rather than a natural conversation thread.

⚠️ 2. Google Sheets API Quota Exhaustion

Updating row-by-row in a loop (e.g. 'Details'!A${rowNum}:Z${rowNum}) makes 1 HTTP call per lead. Processing batches of 200+ leads risks hitting Google's limit of 300 requests/minute (429 errors).

⚠️ 3. Lack of Provider / ESP Matching

Sending indiscriminately across providers (e.g., sending from a free Gmail inbox to a corporate Microsoft 365 Exchange gateway) increases spam filtering. Intra-provider delivery (Google $\to$ Google) is vastly superior.

⚠️ 4. Static Template Repetition

Simple tag substitution sends hundreds of identically structured sentences. Modern spam filters use statistical pattern recognition to flag identical body structures even if names differ.

3. Deliverability Infrastructure Upgrades (Smartlead Standard)

✉️ RFC 2822 Threading

Capture initial sendResult.messageId and inject it into follow-up In-Reply-To and References headers for native inbox grouping.

🎯 ESP Matching Router

Inspect recipient MX records. Route Google Workspace recipients through Google inboxes and Microsoft 365 recipients through Outlook inboxes.

🔀 Nested Spintax Engine

Support recursive dynamic variations: {Hi|Hey|Hello} {{full_name}}, {saw your post|noticed your company} to ensure every outgoing email is syntactically unique.

🚦 Pre-Flight DNS Auditor

One-click verification tool to inspect SPF, DKIM, and DMARC alignment on all connected sending inboxes before launching campaigns.

📄 Dual-MIME & Stealth Mode

Send clean multipart text/plain + text/html without bloated tracking pixels for maximum reputation safety.

🛑 1-Click Unsubscribe

Inject RFC 8058 List-Unsubscribe and List-Unsubscribe-Post headers to comply with 2025/2026 Google & Yahoo bulk sender mandates.

// Drop-in RFC 2822 Threading Implementation Blueprint for engine.mjs
const mailOptions = {
  from: `"${senderName}" <${senderEmail}>`,
  to: email,
  subject: finalSubj,
  html: finalBody,
  headers: {
    ...(previousMessageId ? {
      'In-Reply-To': previousMessageId,
      'References': previousMessageId
    } : {}),
    'List-Unsubscribe': `<mailto:unsub@${senderEmail.split('@')[1]}?subject=unsubscribe>`,
    'List-Unsubscribe-Post': 'List-Unsubscribe=One-Click'
  }
};

4. Clay-Style Waterfall Data Enrichment & Verification

🔌 1. Free Deep SMTP Handshake Probe

Beyond simple MX lookups, open a lightweight socket to destination port 25 to test RCPT TO and catch dead mailboxes and catch-all servers without paying for verification services.

🌊 2. Multi-Vendor Waterfall Connectors

Optional plug-and-play API connectors (Hunter, Prospeo, Findymail, Dropcontact). If provider A returns no email, automatically query provider B to maximize match rate.

🧠 3. AI Prospect Intelligence (Claygent)

Scrapes the lead's company homepage and asks Groq LLM to summarize their exact value proposition, generating a personalized 1-sentence opening icebreaker.

🏷️ 4. Company Technographics

Detect technologies in use on target domains (e.g. Shopify, React, HubSpot) to trigger hyper-relevant niche templates automatically.
